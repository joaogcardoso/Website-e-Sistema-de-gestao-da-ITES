# Builder integration

Port document operations, registry, selected catalog blocks, Canvas, Catalog, PropertyEditor, PreviewPage and publication controls. ITES allowlist: hero, rich text, cards, news, contact, call to action. Server validates block/property/URL/size; no scripts or event attributes. Unknown blocks are inert placeholders and cannot publish. Auth, demand forms, decision controls and private data are never blocks. Stable slug identifies page; JSONB draft versions and published pointer persist with revision. Save needs `builder.pages.edit`; publish needs `builder.pages.publish`; templates need `builder.templates.manage`. Frontend reflects effective grants, backend enforces. Publish pointer and audit atomic. Verify access, conflict, reload, preview, publish, public rendering and protected workflow after edits.
